# TECHFEST — Landing Page Concept

A responsive, single-page landing page concept for Techfest, IIT Bombay (2026–27).

## Design direction

**“The Future Is a Live Experiment.”** A cinematic editorial direction: near-black canvas, electric violet and acid-lime accents, warm gold details, oversized typography, scientific linework and a subtle 2D particle field. The experience is deliberately built without 3D assets, WebGL, frameworks or build tooling.

## Features

- Responsive desktop and mobile navigation
- Animated 2D canvas particle field (no 3D)
- Pointer-reactive glow and interactive particle response
- Scroll-triggered section reveals
- Animated marquee, orbital motif and hover states
- Sections for the festival story, arenas, experiences and impact
- Reduced-motion support
- Calls to action link to the official Techfest website

## Run locally

Open `index.html` directly, or run:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000.

## Publish on GitHub Pages

1. Create a public GitHub repository, e.g. `techfest-landing-page`.
2. Upload `index.html` and `README.md` to the repository root.
3. In **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. GitHub will provide the public Pages URL after deployment.

## Demo recording

Record a 30–60 second walkthrough (desktop full-screen, scroll from hero through the sections, show the mobile layout if possible). Save as MP4, upload to Google Drive, then set **General access → Anyone with the link → Viewer**. Paste that Drive URL into your submission.

## Accuracy note

This is an independent design concept, not an official Techfest website. The 2026–27 prize-pool and workshop-domain figures are based on public launch coverage; verify all live event details, dates, eligibility and registration links on https://techfest.org/ before publishing. The page intentionally avoids invented event names, speaker names and dates.
